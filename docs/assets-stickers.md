# Stickers y logos del universo

- Los nueve archivos iniciales de `public/stickers/` se extrajeron de las dos páginas de
  `C:\Users\Usuario\Desktop\plancha-agarrate-la-tanga-a5_v28.pdf` que entregó
  el usuario. Se mantuvo el arte original y se separó cada silueta de su fondo
  de plancha para mostrarla individualmente. Son WebP con transparencia.
- `public/stickers/agarrate-la-tanga.webp` usa la imagen «AGARRATE LA TANGA»
  que el usuario adjuntó el 29 de septiembre de 2026; conserva el texto y el
  borde de sticker sobre transparencia.
- `public/universo/gran-berta.webp` proviene de `Perfil Monograma.jpg` del
  branding de Gran Berta.
- `public/universo/bani-vfx.webp` proviene de `Logotipo Negativo (Perfil).jpg`
  del branding de Bani VFX.
- `public/universo/bani-monograma.webp` usa el monograma negativo de Bani VFX
  proporcionado por el usuario el 29 de septiembre de 2026.
- `public/universo/totem.webp` proviene de `negro.jpg` del branding de Totem.
- Las fuentes maestras permanecen fuera del repositorio. Los archivos web se
  redujeron de tamaño para cargar en la página.
